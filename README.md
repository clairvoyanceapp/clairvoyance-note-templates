# Clairvoyance Note Templates

Note templates for [Clairvoyance](https://www.clairvoyanceai.com), shown in the **New Template** menu and on the Templates HomeDesk tile.

## Install

Copy a `.json` file into `config/templates/` in your Clairvoyance data folder (Windows: `%APPDATA%\clairvoyance\config\templates\`), then restart Clairvoyance. Give your own variations a new file name, because files that ship with the app are refreshed on launch.
